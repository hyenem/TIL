# 컴퓨터 운영의 지휘자 운영체제(25.01.23)
* Proccess
    * Ready : 준비는 다 됐는데, CPU를 점유하지 못해서 대기하고 있는 상태(우선순위 이슈 등)
    * RUN : 선택된 1개의 process가 돌고있는 것
    * RUN하다가 시간 만료되거나 다른 우선순위가 선점하면 다시 Ready상태로 감
    * RUN 조금하다가 context switching이 되면 너무너무 비효율적이라 어느정도 기다리게함
    * 그런데 자동차, 항공기 이런거는 그러면 너무 위험하니까 그냥 선점하게함 : RealTime OS
    * wait(sleep == block) : 마우스 클릭, 키보드 입력 전까지 할 일 없는데, 스케쥴링 되고있으면 너무 비효율적이니까 차단해두는 것. 즉, 이벤트 발생을 기다리며 자고있는 상태. 이벤트가 발생하면 준비로 감.
