# 컴퓨터 시스템의 구조(25.01.22~23.)
* 워드 : 데이터 버스의 폭
    * 데이터버스 폭이 4바이트
    * 레지스터가 4바이트
    * 계산 결과가 4바이트보다 작으면 남은 비트를 복사하는게 오래걸림
    * 그래서 그냥 다 4바이트 단위로 처리함
* 1B = 256
* 1K = 2^10 비트

* 제어장치(fde)
    * fetch : 프로그램카운터 주소가 디코더에 의해서 선택됨
    * decode : 오피코드 오퍼랜드 읽어서 ALU의 시행준비
    * excute
    * exception
        * exception이 발생하면 하드웨어적으로 해결
        * 현재 context를 stack에 쌓고, handler로 처리하고, 스택에서 팝해서 레지스터 등을 원상복귀시킴
        * sw에서는 시스템콜(출력등)만 가능

    * CISC : 빠르지만 비싸다(명령어 수가 많아서 트렌지스터가 많이 들어감)
        * 명령어 길이가 다르다
        * 파이프라인 : 23클럭이나 필요함. 왜냐하면 F, D, E를 곧바로 겹치게 동작시키는데, 끝났는지 안끝났는지 채크해야하니깐. 이때 캐시를 이용함
    * RISC : 느리지만 저전력 저렴

* 기억장치(RoM, RAM, 계층구조)
    * RAM(Random Access)
        * DRAM은 1을 주고 떨어지면 0이 되기전에 다시 리브페시
        * SDRAM 클럭마다 읽기
        * DDR SDRAM 클럭 올라갈떄랑 떨어질 때 읽기
    * ROM(Read Only)
    * 지금은 DDR SDRAM + Flash Memory
