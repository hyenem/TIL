# Java가 익숙한 분들을 위한 팁
* java에서는 int와 char가 모두 정수형이라 형변환만 해주면 아스키코드를 바로 알수가 있었는데요,
* python에서는 그렇지 않습니다.
* 아스키코드를 char로 바꿀때에는 chr(), char를 아스키코드로 바꿀때에는 ord()를 사용합니다.
```python
ascii_code = ord('a')
print(ascii_code)  # 출력: 97

char = chr(97)
print(char)  # 출력: 'a'
```

# 다차원 배열 정렬과 관련하여
* 알고리즘을 풀다보면 이차원 배열을 정렬할 일이 생깁니다.
* `[[1,2,3], [2,0,9], [2,3,4]]`라는 배열이 있을 때 해당 배열을 0,1,2번 인덱스를 기준으로 각각 정렬하고 싶을 수 있습니다.
* 그럴 때에는 `key`라는 속성을 이용하면 좋습니다.
* 예제를 보면 사용 방식을 바로 알 수 있습니다.
```python
arr=[[1,2,3], [2,0,9], [2,3,4]]
arr.sort(key =  lambda x : x[1]) #1번 인덱스를 기준으로 정렬합니다.
arr #[[2,0,9], [1,2,3], [2,3,4]]
```

# 파이썬보다 다른 언어가 익숙한 분들을 위한 꿀팁
* JAVA에서는 for문을 돌 때 한바퀴돌때마다 조건을 채크해서 또 돌지말지를 판단합니다.
* 그런데 python에서는 for 문이 돌기 시작할 때 몇 번 반복할지, 어떤 변수를 가지고 돌지가 고정됩니다.
* 아래의 문제가 while문 개념보다 앞에 나오는 줄 알고(ㅠㅠ) while문도 안쓰고, sample() 함수도 안쓰고 for문으로 풀어보려다가 마주한 문제입니다.
* **numbers2**를 구성하는 과정에서 적은 `i-=1`은 아무런 효력을 발휘하지 못합니다.
* 해당 경우에서 i는 **처음에 결정된 0부터 5까지 6번 반복됩니다.**
* for문 구조상,, 당연한 건거 같기도 하지만용,,,
```
# Lotto : 임의의 값 6개가  항상 중복되지 않게 출력되도록 구해 보자.
#아래 풀이는 옳습니다.
import random as r
numbers = r.sample(range(1, 46), 6)
numbers

#아래 풀이는 옳지 않습니다.
numbers2 = set()
for i in range(6):
    tmp = len(numbers2)
    numbers2.add(r.randrange(1, 46))
    if tmp == len(numbers2):
```
