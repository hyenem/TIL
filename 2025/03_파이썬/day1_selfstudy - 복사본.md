## if문 안쓰고 최대값 갱신하기
* 문제를 풀다보면 for문을 돌면서 어떤걸 계산하고, 그 계산값으로 최대값을 갱신해야 하는 상황이 많은데요,
* if문으로 처리할수도 있지만,,, 귀차니즘에 걸린 저에겐 아래와 같은 방법이 더 잘 맞더라구요.
```python
#방법 1
if now>maximum :
    maximum = now
#방법 2
maximum = max(maximum, now)
```

## 비트연산과 관련하여
* 오늘 진법에 대해 배워서 비트연산에 대해 소개해보려합니다.
* 비트 연산은 10진수가 아닌 2진수를 사용하는 방식인데요.
* https://dojang.io/mod/page/view.php?id=2460
* 저는 비트 연산을 주로 bfs에서 visited를 처리하거나, 조합을 만들 때 사용합니다.
```python
# 조합 만들기
# 세 명의 사람이 있고, 각 사람이 포함되거나 포함되지 않는 모든 경우에 대해 연산을 해야 한다면, 아래와 같이 구성할 수 있습니다.
for i in range(8):  # 0부터 7까지 (총 8가지 경우의 수)
    binary = format(i, '03b')  # 이진수로 변환하고, 3자리로 0을 채워줍니다.
    print(binary)
# 이렇게 하면 000, 001, 010, 011, ..., 111까지 나오는데,
# 0은 포함되지 않음, 1은 포함됨으로 생각하고 처리할 수 있습니다.

# 방문 처리하기
# 이진수의 i번째 자리를 visited 배열의 i번째 인덱스처럼 사용할 수 있습니다.
visited = 0
# 예를 들어 3번 인덱스 칸을 방문하려는 경우:
# 1. 우선 이전에 방문했었는지 확인합니다.
# 전체 칸의 개수가 n이라고 가정합니다.
if not (visited & (1 << 3)):  # 3번째 비트가 0인 경우 (방문하지 않은 경우)
    dosomething(3)  # 3번 인덱스에 대해 필요한 작업을 수행하고,
    visited |= (1 << 3)  # 3번째 비트를 1로 설정 (방문 처리)
```
